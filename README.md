# Tuwafute Machozi

Luxury travel house for Zanzibar and Tanzania — Discover. Experience. Give Back.

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion · GSAP · Lenis · React Three Fiber

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Hero video and stills live in `public/media` and `public/images`.
- Update WhatsApp in `src/content/brand.ts`.
- Enquiry submissions are logged by `app/api/enquire` — connect email later.
